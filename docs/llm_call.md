## 所需要的包管理工具
[uv](https://github.com/astral-sh/uv)

## 需要的环境变量
```bash
export DASHSCOPE_API_KEY="your_api_key"
```

## 提前需要的命令
拉取这个仓库，或者自己在一个文件夹中运行
```bash
uv init
```

uv add openai
